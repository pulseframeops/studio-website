06 / FAQ

Частые вопросы.

Немного важных подробностей перед запуском альфы.

PulseFrame действительно бесплатный?

Да. Исходный код опубликован под лицензией MIT, платная подписка для работы программы не нужна.

Почему в архиве нет установщика?

v0.2.6 Alpha выпущена как исходный пакет. Для десктопного запуска установи Node.js, выполни npm install и npm start. Отдельных .exe/.dmg/.AppImage пока нет.

Можно ли экспортировать MP4 прямо в браузере?

Нет. Браузерная версия предназначена для предпросмотра. Для MP4 нужен запуск через Electron и доступный FFmpeg, в том числе портативный. Экспорт альфы ещё требует тестирования.

Есть версия для Android или iPhone?

Android пока в планах. Версии для iOS на данный момент не анонсировано. Сейчас PulseFrame ориентирован на ПК.

Куда писать о найденных ошибках?

Лучше всего создать Issue на GitHub с описанием ошибки, шагами воспроизведения и информацией об операционной системе.
