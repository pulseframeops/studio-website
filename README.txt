PulseFrame Studio Website • v0.2.6 Alpha
======================================

Static promotional website for PulseFrame Studio Alpha v0.2.6.

WHAT'S INCLUDED:
  • Fully responsive one-page design
  • Russian / English language toggle
  • Audio-reactive canvas demo. Upload your own audio to test live visualization.
  • Real screenshots captured from the 0.2.6 HTML preview (no 0.2.7 features)
  • Download link to the existing v0.2.6 Alpha source ZIP on GitHub
  • Quick start and known limitations
  • Links to Telegram, X, GitHub, GitHub Issues, and email
  • No build tools or frontend dependencies required

NOTES:
  This website is not the PulseFrame app. The interactive hero visualizer is a
  lightweight demo on the website, not a live instance of PulseFrame itself.
  The site will work without a network connection aside from links and the optional
  Google Fonts stylesheet (fallback system fonts are available).
  The v0.2.6 download is a SOURCE ARCHIVE, not an installer.
  Do not call it a prebuilt .exe/.dmg/.AppImage.

ASSETS:
  assets/real-app-*.webp - captured from the provided 0.2.6 HTML preview.
  assets/pulsy-jessica.webp, assets/brand-art.webp - artwork made for PulseFrame Studio.
  assets/icons.svg - icon symbols drawn in the style of Lucide (ISC license).
  Typography: Montserrat / Space Grotesk, loaded from Google Fonts when online.
  Icon inspiration/license: https://lucide.dev/license
